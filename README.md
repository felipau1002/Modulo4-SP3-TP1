# Trabajo práctico N° 2 - Sprint 2

## Qué es

Página de catálogo de juegos con una opción para agregarlos a una wishlist


## Como ejecutarlo

npm i && npm run dev


## Herramientas utilizadas

- Visual Studio Code
- React
- TailwindCSS
- Chat ia de visual studio code


## Qué hizo la ia

En este tp utilicé el chat de ia de visual studio para tres cosas: crear el json con todos los juegos, crear los estilos con tailwind y hacer funcionar el custom hook "useInput" para utilizar un buscador en la página que filtre los juegos que coincidan con lo que se escribe en el input
